# FileSorter
**Умный CLI-сортировщик и очиститель файлов для Linux.**

FileSorter помогает разработчикам, DevOps и системным администраторам автоматически наводить порядок в директориях: раскладывает файлы по категориям и безопасно удаляет/архивирует старые логи и артефакты.

## Возможности
- **Автоматическая сортировка** по расширениям в заданные папки.
- **Безопасная очистка** старых файлов через `trash-cli` (с возможностью восстановления) или перенос в архив.
- **Dry-Run режим** для предварительного просмотра плана без изменения файловой системы.
- **Гибкая настройка** через YAML-конфигурацию.
- **Автоматизация** через `cron`.

## Быстрый старт

### 1. Установка зависимостей
```bash
# Системная утилита для безопасного удаления
sudo apt update && sudo apt install trash-cli

# Python-библиотека для работы с YAML
pip install -r requirements.txt
```
